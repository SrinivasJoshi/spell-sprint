# A custom on-screen keyboard instead of the native one

On touch devices the Blanks are filled from our own A–Z keyboard, and the native keyboard is never opened. Turning off autocorrect does not remove iOS and Android predictive suggestions, which would show the correct spelling after a few letters and defeat a spelling test. Do not replace this with a native `<input>` to simplify it; desktop uses the physical keyboard feeding the same Blanks.
